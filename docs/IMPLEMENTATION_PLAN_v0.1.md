# MediaLoader — Implementation Plan v0.1

## Цель

Создать базовый Android-каркас приложения MediaLoader версии 0.1.0-alpha01.

На этом этапе реализуется фундамент приложения без реальных алгоритмов получения медиа.

---

# Этап 1 — Foundation

Создать Android-проект:

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose

Настроить:

- Gradle
- зависимости
- структуру пакетов
- тему приложения
- версионирование

Результат:

Приложение собирается и запускается.

---

# Этап 2 — Core

Создать базовые модели:

- MediaItem
- MediaType
- DownloadTask
- DownloadState

Модели не должны зависеть от конкретных источников.

---

# Этап 3 — UI каркас

Создать экраны:

- HomeScreen
- DownloadsScreen
- SettingsScreen
- PreviewScreen

Использовать тестовые данные.

Функциональность загрузки отсутствует.

---

# Этап 4 — Data слой

Подготовить:

- Room database
- хранение истории загрузок
- хранение настроек

Настройки включают:

- папку сохранения
- параметры интерфейса

---

# Этап 5 — Downloader слой

Создать каркас:

- DownloadManager
- QueueManager
- StorageManager

Подготовить работу с:

Download/MediaLoader

Сохранение:

- оригинальных имён файлов
- добавление _1, _2 при конфликте

---

# Этап 6 — Provider архитектура

Создать интерфейс:

MediaProvider

Назначение:

Каждый источник имеет собственную логику получения данных, но возвращает единый формат.

Подготовить:

- InstagramProvider (заглушка)
- возможность добавления YouTubeProvider в будущем

---

# Порядок разработки

1. Foundation
2. UI каркас
3. Модели
4. Data слой
5. Downloader каркас
6. Provider интерфейсы
7. Первый APK

---

# Ограничения версии 0.1.0-alpha01

Не реализуются:

- реальные загрузки Instagram
- авторизация
- Stories
- YouTube
- сложная обработка медиа

Цель версии — получить стабильный фундамент для дальнейшего развития.
