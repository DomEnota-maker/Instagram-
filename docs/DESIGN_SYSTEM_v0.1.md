# MediaLoader — DESIGN_SYSTEM v0.1

## Назначение

Документ описывает визуальное направление приложения MediaLoader на основе UX-концепта интерфейса.

Изображения-концепты используются как направление дизайна, но не являются пиксельным эталоном. Ошибки генерации изображений не переносятся в реализацию.

Пример: некорректно расположенные иконки, артефакты поверх превью, искажения элементов интерфейса.

---

# Общий стиль

Направление:
- современный Android-интерфейс;
- минимализм;
- тёмная тема как основной вариант;
- акцентные элементы без перегрузки;
- большое внимание к читаемости.

Цель:
создать ощущение лёгкого профессионального инструмента, а не перегруженного загрузчика.

---

# Цветовая концепция

Основа:
- тёмный фон;
- светлые карточки/тексты;
- один акцентный цвет для действий.

Акцентный цвет используется для:
- кнопки загрузки;
- активных состояний;
- прогресса.

Не использовать акцентный цвет для каждого элемента.

---

# Компоненты

## Карточки

Использовать:
- скруглённые углы;
- достаточные отступы;
- понятную иерархию информации.

Карточки применяются для:
- истории загрузок;
- найденных файлов;
- активных загрузок.

---

## Кнопки

Основные действия:
- Проверить ссылку;
- Скачать;
- Скачать выбранное.

Кнопки должны быть заметными, но не занимать весь экран без необходимости.

---

# Экраны

## Главный экран

Элементы:
- название приложения;
- поле ссылки;
- кнопка проверки;
- последние загрузки.

---

## Предпросмотр

Элементы:
- превью контента;
- источник;
- список найденных файлов;
- выбор элементов;
- информация о размере.

Все найденные элементы отмечены по умолчанию.

---

## Загрузка

Показывать:
- имя файла;
- прогресс;
- размер;
- возможность отмены.

---

## История

Карточка содержит:
- превью;
- источник;
- тип файла;
- размер;
- дату.

Действия:
- открыть;
- поделиться;
- удалить.

---

# Хранение файлов

Стандартная папка:

Download/MediaLoader

Пользователь может изменить папку сохранения в настройках.

Правила именования:
- сохранять оригинальное имя файла;
- не добавлять дату, ник или название приложения;
- при нескольких одинаковых файлах добавлять индекс:
  - file.jpg
  - file_1.jpg
  - file_2.jpg

---

# Нижняя навигация

Основные разделы:

- Главная;
- Загрузки;
- Настройки.

Предпросмотр является временным экраном и не находится в основном меню.
