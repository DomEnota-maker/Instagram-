# Загрузчик — UX Guide v0.2

## Назначение
Этот документ описывает утверждённый UX-каркас приложения. Он является ориентиром для реализации интерфейса, а не строгим графическим макетом.

## Важно
Изображения, созданные для визуализации интерфейса, являются концепцией. Артефакты генерации не переносятся в приложение.
Пример: некорректная иконка музыки поверх изображения на одном из концептов является ошибкой генерации.

## Главный экран

Основной сценарий:
1. Пользователь открывает приложение.
2. Вставляет ссылку.
3. Нажимает проверку.
4. Получает предпросмотр.

Элементы:
- поле ссылки;
- кнопка проверки;
- предложение вставить ссылку из буфера при обнаружении URL;
- блок последних загрузок.

## Предпросмотр

Показывает:
- превью контента;
- источник;
- автора (если доступно);
- список найденных файлов;
- размер.

Для нескольких файлов:
- все элементы отмечены по умолчанию;
- пользователь может снять отдельные галочки;
- быстрый выбор: всё / только фото / только видео;
- отображение количества выбранных элементов.

## Загрузки

Отдельно от истории:
- активные загрузки;
- прогресс;
- скорость;
- возможность отмены.

После завершения элемент переносится в историю.

## История

Карточка содержит:
- превью;
- источник;
- тип файла;
- размер;
- дату.

Действия:
- открыть;
- поделиться;
- удалить.

## Настройки

Минимальный набор:
- папка сохранения;
- уведомления;
- тема;
- восстановление удалённых;
- информация о версии.

## Хранение файлов

Папка по умолчанию:

Download/MediaLoader

Пользователь может изменить путь в настройках.

## Имена файлов

Правила:
- сохранять оригинальное название файла;
- не добавлять дату, ник или название приложения;
- при нескольких файлах добавлять индекс в конец.

Пример:
photo.jpg
photo_1.jpg
photo_2.jpg

Если оригинальное имя отсутствует:
создавать короткое имя вида media_001.

## UX-принципы

- минимум действий до результата;
- никаких рекламных или лишних экранов;
- пользователь всегда видит что скачивается, размер и место сохранения;
- понятные сообщения об ошибках.
