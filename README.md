# MediaLoader 0.1.0-alpha04

Android-приложение на Kotlin и Jetpack Compose. Интерфейс основан на эскизе проекта: тёмные карточки, фиолетовые действия, экраны ссылки, предпросмотра, загрузок и настроек. Иконка предоставлена автором.

## Реализовано

- Приём ссылки вручную или через Android «Поделиться».
- Провайдер Instagram для публичных публикаций, Reels и каруселей. Он читает открытые данные страницы из встроенного JSON с проверкой ID публикации, затем пробует метаданные (`og:video`/`og:image`) и публичную embed-страницу. Авторизация не используется. Если Instagram не выдаёт прямой адрес файла, показывается ошибка доступа. Stories, закрытые публикации, вход, MP3 и выбор качества пока не реализованы.
- Выбор найденного элемента, загрузка системным DownloadManager в `Download/MediaLoader`, суффиксы `_1`, `_2` при совпадении имени.
- История и статусы в Room, системные уведомления, открытие и отмена задач. Размеры показываются в КБ и МБ.

## Проверка

CI использует JDK 17, Android SDK 35 и Gradle 8.9: `:core:testDebugUnitTest :app:lintDebug :app:assembleDebug`. Собирается только подписанный стандартным debug-ключом APK.

Публичный HTML Instagram меняется и может требовать вход даже для открытой страницы. Доступность конкретной ссылки надо проверять на устройстве; результаты не подменяются демонстрационными данными.
